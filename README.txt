MINIJUEGO LÍNEA PERFECTA · GLOW UP

Cómo usarlo:
1. Abre index.html en el navegador.
2. También puedes subir toda la carpeta a GitHub Pages, Netlify, Firebase Hosting o cualquier hosting estático.
3. No necesita internet, librerías externas ni instalación.

Qué se corrigió/mejoró:
- Carpeta renombrada sin caracteres raros para evitar rutas dañadas.
- Se eliminaron módulos ES import/export para que funcione al abrirlo localmente.
- Canvas responsive con soporte para celular, mouse y pantallas de alta densidad.
- Sistema de trazo más jugable: si se suelta antes del final, se puede continuar desde el último punto.
- Nueva evaluación de precisión más justa: mide distancia real contra la ruta, progreso, control, fluidez, tiempo y longitud del trazo.
- Modo práctica con guía más generosa.
- Progreso guardado con localStorage.
- Diseño visual más limpio, claro y estilo Musicala.
- 8 niveles completos.

Archivos principales:
- index.html: estructura del juego.
- styles.css: diseño visual.
- game.js: lógica, niveles, scoring y dibujo canvas.
